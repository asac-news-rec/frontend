# 사이 뉴스 화면 초안

한국어 개인화 뉴스 서비스의 팀 피드백용 정적 프로토타입입니다. `사이 뉴스`는 교체 가능한 임시 이름입니다. 실제 뉴스 보도, 추천 모델, 행동 수집 서버는 연결하지 않았습니다.

## 실행

Node.js 22 이상을 권장합니다. 외부 패키지 설치가 필요하지 않습니다.

```powershell
npm start
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. 서버는 로컬 접속만 허용합니다. 팀 공유 호스팅은 별도로 설정해야 합니다.

```powershell
npm run check
npm test
npm run build
```

`dist/`는 정적 호스팅용 결과물입니다. 백엔드 없이 HTML, CSS, JavaScript를 제공합니다. 해시 경로를 사용하므로 기사 상세 새로고침을 위한 별도 서버 라우팅은 필요하지 않습니다.

## 화면 확인 순서

1. 상단의 독자를 김하늘에서 이도윤으로 변경해 첫 기사와 추천 이유를 비교합니다.
2. 카테고리를 선택하고 기사 상세로 이동합니다.
3. 피드로 돌아와 독자와 카테고리가 유지되는지 확인합니다.
4. 새로운 독자를 선택해 이력 없는 상태의 최신순 피드를 확인합니다.
5. 하단의 팀 검토용 메뉴에서 느린 로딩, 기사 없음, 조회 실패를 선택합니다.
6. 오류 화면에서 다시 시도를 눌러 정상 피드로 복구합니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| src/data.js | 가상 독자 3명, 가상 기사 8개, 독자별 샘플 순서와 JSDoc 자료형 |
| src/service.js | 샘플 조회와 추천 묶음 생성. 실제 API 교체 위치 |
| src/app.js | 화면 상태, 독자·카테고리 전환, 기사 상세, 안전한 본문 출력 |
| src/style.css | 반응형 레이아웃, CSS 그래픽, 키보드 포커스 |
| server.mjs | 외부 의존성 없는 로컬 서버 |
| tests/feed.test.js | 독자별 차이, 신규 독자 정렬, 필터, 오류·빈 결과·복구 검증 |
| DESIGN_NOTES.md | 구현 내용, 선택 이유, 팀 피드백 질문과 제한 |

## 검증 결과와 제한

2026-10-29, Node.js v24.19.0에서 문법 검사, 동작 테스트 4개, 정적 빌드를 통과했습니다. 테스트는 서비스 함수의 실제 반환값을 확인합니다. 브라우저 렌더링·키보드 조작·모바일 화면·실제 클릭 테스트를 대신하지 않습니다.

2026-10-29, 로컬 서버를 실행하고 브라우저에서 첫 화면이 표시되는 것을 확인했습니다. 키보드 조작, 기사 클릭 흐름, 모바일 화면과 넘침 검증은 남아 있습니다.

백엔드 계약, 사용자 인증, 모델 예측, 외부 이벤트 전송, 관심사 학습, 데이터 파이프라인 연결은 구현 범위가 아닙니다. 샘플 독자의 ID와 기사의 ID, 샘플 추천 묶음 ID만 분리했습니다. 새로고침은 동일 샘플을 다시 읽고 목록 생성 시각을 갱신합니다.
