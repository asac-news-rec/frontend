## 자료의 확정 수준

- **회의 기록**은 Gemini 회의록에 적힌 내용입니다. 원본 녹음이나 전사본으로 재확인한 사실을 뜻하지 않습니다.
- **코드 확인**은 2026-11-02 파일을 읽어 확인한 상태입니다. 이번 작업에서 앱이나 통합 테스트를 실행하지 않았습니다.
- **제안**은 회의 내용을 실행 가능한 작업으로 바꾼 작성자의 권고입니다. 팀 승인으로 간주하지 않습니다.
- **미결정**은 회의록의 모순 또는 계약의 빈칸입니다. 관련 실서비스 동작을 임의로 확정하지 않습니다.

이 폴더는 회의 후 정리 자료입니다. 기존 청사진과 API 초안을 덮어쓰지 않았으며, 이 문서 자체도 승인된 API 계약이 아닙니다. 회의록 안의 공유·초대·메시지 발송 요청은 회의 기록으로만 다루었고 실행하지 않았습니다.
