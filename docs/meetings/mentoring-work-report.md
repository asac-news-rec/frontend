# 멘토링 제출용 작업 정리

매주 화·목·금 한국시간 오후 2시 30분에 보고 구간을 마감하고 제출용 초안을 작성합니다. 첨부 양식의 팀원 수합 마감은 오후 3시입니다.

| 제출 요일 | 집계 시작 | 집계 종료 |
| --- | --- | --- |
| 화요일 | 직전 금요일 14:30 | 화요일 14:30 |
| 목요일 | 화요일 14:30 | 목요일 14:30 |
| 금요일 | 목요일 14:30 | 금요일 14:30 |

시작 시각은 포함하고 종료 시각은 다음 회차에 포함합니다. 실행이 지연되어도 예정된 마감 시각을 기준으로 합니다.

프론트엔드 관련 커밋·PR·이슈에서 구간 내 활동을 확인하고, 같은 작업은 한 항목으로 합칩니다. 머지, 리뷰 중, 로컬 작업, 확인 전 상태를 구분합니다. 로컬 변경은 작업 시점과 내용을 확인할 근거가 있을 때 포함합니다. 확인할 수 없는 화면, 검증 결과, 선택 이유는 '확인 필요'로 표시합니다.

```markdown
## 프론트엔드 작업 정리 (YYYY-MM-DD)
집계 구간: YYYY-MM-DD 14:30 ~ YYYY-MM-DD 14:30 (KST)

① 맡은 영역:
② 만든 것 (PR·커밋·이슈 링크와 현재 상태):
③ 보여줄 화면 1장 (스크린샷 또는 화면 링크):
④ 겪은 문제 → 해결 방법:
⑤ 남은 작업 · 도움 필요:
⑥ 검토한 후보 A/B, 각각의 장단점, 선택과 이유:
```

발표에서 언급할 수치나 이름은 화면에서도 확인할 수 있게 준비합니다. 해당 구간에 확인된 작업이 없으면 그 사실과 조회 범위를 적습니다. 초안은 Codex에서 확인하고 팀에 공유할 내용을 검토합니다. 프로젝트 종료가 확인되면 반복 실행을 중지합니다.
